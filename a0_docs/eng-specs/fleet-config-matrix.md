Classes: **config** — user-facing setting that defines "my configuration": migrates to a new phone (exported, diffed, applied).; **secret** — a credential: migrates through the vault, always masked on screen (exported only to fleet-signed callers).; **device** — never migrates: install ids, device keys, caches, cursors, trackers, sync state, migration markers.; **content** — user data that lives on a server or in the shared store: only the account link migrates, never the bytes.
