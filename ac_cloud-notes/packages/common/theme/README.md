# @cloud-notes/theme

Design tokens for Cloud Notes: the CSS custom properties (`--cloud-notes-*`), the
typed variable maps and the typography presets.

This directory is vendored from a package published under the Mozilla Public
License 2.0 (see `LICENSE`). Modifications: the build output only, with the
variable and type names renamed to Cloud Notes naming and the source maps and
font files left out. The files stay under MPL-2.0; the rest of the repository
is covered by the licences in `LICENSING.md`.
